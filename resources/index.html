Offline & export

The web reader is the primary experience, but the draft is also plain markdown you can archive, grep, or feed into your own tools.

  • Full manuscript — single concatenated markdown file (~31k words)
  • manifest.json — section order, word counts, citation lock flags
  • search-index.json — plain-text index for agents and local search
  • Book reader — per-section download and print from the section toolbar

Heading links inside a section look like #chapter-10-the-eu-ai-act-is-a-calendar — copy from the # anchor beside any subheading.
